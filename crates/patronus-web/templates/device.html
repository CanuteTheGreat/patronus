SSH keys

{% if can_modify %}
{% endif %}

Keys let these accounts log in over SSH without a password. Only public keys are accepted (ed25519, ECDSA, RSA of 2048 bits or more), without options. Root's last key cannot be removed while root has no password, so nobody is locked out. Every change is in the audit log.

Lights

{% if can_modify %}
{% endif %}

"Off" darkens every light of the device, at once and after every start (handy in a bedroom). "On" brings back the device's own status and activity lights.

Scheduled restart

{% if can_modify %}{% endif %}

Off unless you switch it on. A restart takes the device offline for about a minute; clients reconnect by themselves. The time is the device's own clock (UTC unless a time zone is set under System).
