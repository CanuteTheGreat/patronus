Gateways

A gateway is an upstream router behind one interface. Leave the address empty for a dynamic gateway (DHCP, PPPoE, IPv6 router advertisements): Patronus uses whatever default route that interface currently has. {% else %}

Members are gateway:tier[:weight]. The lowest tier with a usable member carries the traffic; several usable members in that tier share it by weight; when the whole tier fails the next tier takes over. The trigger decides what makes a member unusable.
