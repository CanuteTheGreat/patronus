DHCP failover

Both nodes serve the same DHCP pools with Kea's high-availability hook: every lease is copied to the peer as it is granted, so when one node fails the other renews the same addresses within the lease time and keeps handing out new ones. Clients get the LAN virtual IP as default gateway and DNS server while HA is on. The peer address defaults to the sync peer. Needs the Kea DHCP backend (dnsmasq has no failover protocol and is refused). Set one node to primary and the other to secondary.
