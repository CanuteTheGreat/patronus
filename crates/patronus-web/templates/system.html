Updates (Portage)

    
Patronus is a Gentoo system: updates come from Portage. Check syncs the
        tree and lists what would be merged; Update Patronus runs emerge -1u net-firewall/patronus;
        Update everything runs emerge -uDN @world. Jobs run in the background and survive a
        restart of this interface; restart the services (or reboot) afterwards to run the new version.

External login (RADIUS)

    
People whose account is on a RADIUS server can log in here with those credentials
        (PAP over UDP; the answer is verified with the shared secret). The first successful login creates a
        password-less account with the server's default role (never admin: promote it above); disable or delete it
        like any other. Local accounts never fall back to RADIUS, and there is no two-factor step for RADIUS logins
        (use the RADIUS server's own). User names are 1-32 letters, digits, '.', '_' or '-'.
