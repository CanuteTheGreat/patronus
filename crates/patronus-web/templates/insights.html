Extra probes

The gateway monitor pings every gateway. A TCP, HTTP or DNS probe is sent through the gateway's own interface as well, so an ISP that answers ping but has dead DNS shows up as degraded. A critical probe also counts as packet loss for the gateway group's failover.

DNS: the resolver's IP and the name to look up. TCP: an IP and a port. HTTP: a full URL (any answer below 500 counts).

Alerts and retention

Probe failures and recoveries, and SLA breaches, are written to the event log and sent to the webhooks, like gateway up/down events.
