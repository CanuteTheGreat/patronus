Notification matchers

A matcher decides which events a notification channel gets. Build it from groups (all of the items, any of them, or not the one item) holding event kinds, a minimum severity, a name pattern (* and ?) and time windows (weekdays with a start and end time in this box's time zone; an end before the start runs past midnight). Move items with the buttons or drag them; with an item focused, Alt+arrow keys move it (up, down, indent, outdent) and Delete removes it. A channel uses one matcher, chosen in the channel list above.
