# merged AFTER the kernel: kernel modules are built against the installed gentoo-kernel-bin tree.
# Root on ZFS is the Patronus default (owner rule 2026-10-29); common/portage/package.use/00-zfs gives both USE=dist-kernel,
# so every kernel update rebuilds the module in the same transaction, before the new initramfs.
# riscv64 is left out on purpose: the official binhost has no zfs/zfs-kmod there and the image would compile them under emulation.
# The installer then sees no ZFS module (system.zfs_available) and proposes XFS.
x86_64? sys-fs/zfs-kmod
x86_64? sys-fs/zfs
aarch64? sys-fs/zfs-kmod
aarch64? sys-fs/zfs
